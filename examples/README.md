# Demo images

A few images from the **val** split (never used for training or the locked test), resized to 1024 px.
Ground truth (label, defect types, normalised boxes) is in `examples.json`. Regenerate with `python scripts/make_examples.py`.

Source: VisA (Visual Anomaly) dataset, Zou et al., ECCV 2022, https://github.com/amazon-science/spot-diff — licensed CC BY 4.0. Images were resized; no other changes.
